# 拾光清单 Shiguang Todo

一个简洁、温暖的个人任务与专注管理网站。使用 React、TypeScript 和 Vite 构建。

## 功能

- 任务新增、编辑、删除，优先级和截止日期
- 待办 / 进行中 / 已完成三栏看板，支持搜索
- 25 分钟专注与 5 分钟休息，支持暂停和重置
- 任务数量与累计完成专注时间统计
- 浏览器本地保存，适配手机与桌面
- 按截止日期、优先级排序，逾期标记与筛选
- JSON 备份导出、格式校验与确认恢复
- 番茄钟刷新后恢复，完成时显示站内提示

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

打开终端显示的本地地址。

## 构建

```bash
npm run build
npm run preview
```

生产文件位于 `dist/`，可部署到任意静态网站服务。部署到域名子目录时，构建使用 `npm run build -- --base=./`。

## 数据说明

数据仅保存在当前浏览器的 localStorage 中，不会上传服务器，不同浏览器与设备不互通。清除浏览器数据会清空记录。专注计时会保存结束时间，刷新后继续；离开期间到期的阶段在重新打开时结算一次，下一阶段需要手动开始。累计完成次数会保存。导入备份会替换任务和累计次数，建议先导出现有数据。当前版本不包含登录、云同步或通知功能。
